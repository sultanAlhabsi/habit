# إنجاز (Enjaz) — تطبيق تتبع العادات اليومي

تطبيق محمول متكامل وسريع لتتبع العادات وإدارتها، مبني باستخدام **Expo SDK 54 + React Native + TypeScript** وفق فلسفة تصميم هادئة، ناضجة، وطبيعية (Calm & Minimalist) مستوحاة من Things 3 و Apple Notes.

---

## ✨ المميزات الرئيسية

* **واجهة هادئة وطبيعية (Human & Calm Design):** تركيز كامل على المحتوى والعادات مع ألوان محايدة دافئة ولون Accent غابي هادئ (`#2A4B3A`).
* **شريط التاريخ التفاعلي (Weekly Date Strip):** تنقل سلس بين الأيام السابقة والحالية.
* **بطاقة التقدم اليومي:** مؤشر دقيق لنسبة الإنجاز اليومية دون أي بهرجة أو عناصر مشتتة.
* **إدارة متكاملة للعادات:**
  * إنشاء العادات، تعديلها، وحذفها.
  * تحديد الأيقونة، اللون الترابي، ونوع التكرار (يومي أو أيام محددة).
  * تحديد الهدف اليومي ووحدة القياس (دقيقة، لتر، صفحة، مرة...).
* **تسجيل الإنجاز بنقرة واحدة:** تفاعل طبيعي وسريع دون اهتزاز أو حركات ارتدادية مبالغ فيها.
* **عداد الـ Streak والتقويم الشهري:**
  * حساب متواصل للالتزام الحالي (Current Streak) وأفضل إنجاز تاريخي (Best Streak).
  * تقويم شهري تفاعلي (`HabitHeatmap`) يوضح الأيام المنجزة ويتيح التعديل باللمس المباشر.
* **إحصائيات شاملة:**
  * رسم بياني أسبوعي بأعمدة دقيقة ونقية.
  * لوحة ترتيب العادات حسب الاستمرارية.
  * محطات إنجاز (Milestones) رصينة.
* **حفظ محلي دائم (Offline-first):** قاعدة بيانات محلية عبر **Expo SQLite** مع مزامنة فورية وسريعة عبر **Zustand**.
* **دعم الوضع الداكن والفاتح (Light & Dark Mode):** تباين مريح للعين في كافة الأوقات.

---

## 🏗️ التقنيات المستخدمة

* **Framework:** Expo SDK 54 / React Native 0.81
* **Language:** TypeScript
* **State Management:** Zustand 5
* **Database:** Expo SQLite 16
* **Navigation:** React Navigation v7 (Bottom Tabs + Native Stack)
* **Icons:** `@expo/vector-icons` (Ionicons)
* **Animations:** React Native Reanimated

## 🚀 التشغيل والتطوير

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. بدء التطبيق:
```bash
npx expo start
```

* اضغط `a` لفتح التطبيق على محاكي الأندرويد.
* اضغط `i` لفتح التطبيق على محاكي iOS.
* امسح الـ QR code عبر تطبيق **Expo Go** على هاتفك.
