## 2024-05-24 - dayjs object creation bottleneck in loops
**Learning:** Creating `dayjs` objects inside tight loops (like iterating over historical checkins to calculate streaks) causes significant performance degradation due to object allocation overhead. In `calculateHabitStats`, creating a `dayjs` instance on every loop iteration took ~5.6 seconds for 1000 runs.
**Action:** When working with historical dates in loops, use native JS `Date` objects and simple string manipulation (`YYYY-MM-DD` string comparisons) instead of heavy library abstractions. String comparison on ISO-8601 formatted dates is safe and extremely fast. When calculating day differences with native dates, use `Math.round` (not `Math.floor`) to safely handle Daylight Saving Time 23/25-hour day transitions.
