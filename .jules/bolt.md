## 2024-09-16 - Memoizing expensive calculations in UI state transitions
**Learning:** Found a performance bottleneck where `calculateOverallStats` (which has a complexity of O(N * maxBackwardDays) where maxBackwardDays can be up to 3650 for each habit to calculate best streaks) was being called on every render of the HomeScreen. This component also manages frequent state updates like local text input (`searchQuery`) and UI toggles (`isOffScheduleExpanded`). This leads to severe main thread blocking and stuttering during typing and interacting with UI elements because the expensive calculations run redundantly.
**Action:** Always audit components that mix heavy aggregation/computation with fast-updating UI states (like text inputs). In React Native/React, these expensive functions MUST be wrapped in `useMemo` with minimal dependency arrays (`[habits, checkins, selectedDate]`) so they only run when the underlying data actually changes, not when unrelated UI state updates.
